# Bagh-e-Khizar

Bagh-e-Khizar is a modern, responsive website built to present the organization’s information, publications, initiatives, and contact details.

## Live Website

Visit the production website:

https://baghekhizar.org

## Source Code

This repository contains the source code for the live website:

https://github.com/Nafees-khan-29/bagh-e-khizar

## Features

- Responsive design for desktop, tablet, and mobile devices
- Home page
- About page
- Publications section
- Initiatives section
- Contact page
- SEO metadata and organization structured data
- Client-side routing
- Animated user interface elements
- Custom 404 page

## Technology

- React
- Vite
- React Router
- Tailwind CSS
- Framer Motion
- Lucide React
- React Helmet Async
- Netlify
